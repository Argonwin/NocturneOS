🌑 Nocturne OS

Fast. Dark. Fluid. Yours.

Nocturne OS is a custom Android 15-based operating system designed for the OnePlus Nord 3 5G (CPH2493).

The goal of Nocturne OS is to combine the familiarity and usability of OxygenOS 15 with a cleaner architecture, intelligent performance management, smooth 120 Hz animations, and a distinctive dark-violet visual identity.

⚡ Performance Modes

Nocturne OS will provide three hardware performance profiles:

🌙 Silent

Low-power operation for everyday use and long battery life.

⚡ Balanced

The default mode. Smooth animations, responsive UI and intelligent CPU/GPU scaling.

🔥 Performance

Maximum sustainable performance for demanding applications and games.

Performance mode will not disable thermal protection. The system will dynamically select sustainable CPU/GPU frequencies instead of forcing maximum clocks continuously.

🎬 Animation Philosophy

Nocturne OS will preserve the important Android animations:

application opening
application closing
launcher transitions
notification animations
quick settings transitions
lock screen transitions
multitasking animations

The goal is to optimize rendering and frame pacing rather than simply removing animations.

    └── Linux Kernel

📵 Offline Setup

The initial device setup must be possible without an internet connection.

Network-dependent services may require internet access later, but the basic operating system must remain usable offline.

🎚️ Nocturne Switch

The physical Alert Slider will be explored as a hardware controller for Nocturne performance profiles:

🔥 Performance
⚡ Balanced
🌙 Silent


A configurable software option may allow users to restore the traditional Ring / Vibrate / Silent behavior.

🛡️ Safety

Thermal protection and hardware safety mechanisms will not be intentionally disabled.

Performance tuning will focus on:

stable frame times
sustainable CPU/GPU frequencies
reduced unnecessary background activity
efficient power usage
responsive interaction
